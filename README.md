# [Elliptic Curve Arithmetic Visualizer](https://fotihk.github.io/ecc-visualizer/)

A simple graphical webapp allowing you to visualize elliptic curve point arithmetic on any finite field GF(P).

Built using [d3.js](https://d3js.org/). Inspired by two other visualizers: [Elliptic Curves over Finite Fields](https://graui.de/code/elliptic2/) and [The Animated Elliptic Curve](https://curves.xargs.org/)

---
Visit the [hosted version](https://fotihk.github.io/ecc-visualizer/) or serve `index.html` yourself.
